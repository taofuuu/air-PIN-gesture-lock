# Generated model code

Everything else in this folder is generated or copied, so never edit it by hand. It's committed so
the project builds without any ST AI tooling installed, and retraining doesn't need it either.

After `python ml/train.py`, run this from the repo root:

```bash
python ml/reweight.py
```

Retraining changes the weights and the threshold but not the graph, so that rewrites the weights
array in `network_data_params.c`, copies `gesture_model.h` across, and leaves the rest of this
folder alone. It stops with an error if the weights no longer fit the generated array, which is
what a change to the layers in `train.py` looks like.

Only a change to the layers needs the generator, and the generator is **ST Edge AI Core**, not the
X-CUBE-AI pack: since X-CUBE-AI 10.x the pack ships only the STM32CubeMX plugin and TensorFlow Lite
Micro, with no `stedgeai` in it. Install ST Edge AI Core from st.com (2.2.x is what the committed
runtime was generated by) at a short path without spaces, such as `C:\ST\STEdgeAI\2.2`, and run its
`Utilities\windows\stedgeai.exe` from the repo root:

```bash
stedgeai generate --model ml/model/gesture_model.onnx --target stm32f4 --compression none --output <out>
```

Then copy `network*.c` and `network*.h` from `<out>`, and `ml/model/gesture_model.h`, into this
folder.

`Inc/` and `Lib/` are the runtime from that same install (the library is
`Lib/GCC/ARMCortexM4/NetworkRuntime1020_CM4_GCC.a`). They only change with a new generator version,
and then the library's name in `.cproject` changes too.
